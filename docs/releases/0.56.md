# 0.56

Correctif du sol, des personnages et des textes, plus un mini-jeu qui ne plante plus.

- Les shaders ne demandent l'extension GLSL `shadow_lod` que si elle sert (le sol, les personnages et les textes avaient disparu sur le PC de test).
- Mini-jeu mg0107 : 19 fonctions de la libc++ des modules ajoutées, fin du plantage.
- Conversions de texte UTF alignées sur le SDK (noms des joueurs).
- Fichier `env.txt` pour les réglages de test sans recompiler.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
