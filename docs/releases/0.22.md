# 0.22

Sélection des personnages atteinte.

- Profil utilisateur par défaut pour que le jeu charge sa sauvegarde.
- Lecteur vidéo en échec propre quand aucune vidéo n'est décodée.
- Sous-titres de l'intro retirés de l'écran titre.
- Manette tactile de test affichée par-dessus le jeu.

Limites : 3D noire, pas de son.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
