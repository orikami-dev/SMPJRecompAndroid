# 0.33

Le son arrive.

- Audio : mixage des voix et lecture via AAudio.
- Bouton LOG : journal du runtime sur disque, partageable.
- Plusieurs shaders (calcul, textures bindless) traduits en plus.

Limites : décors 3D toujours noirs.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
