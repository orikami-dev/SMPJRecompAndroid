# 0.49

Les décors 3D apparaissent.

- Les listes de commandes en cache ne s'écrasent plus (0.48).
- Les shaders de sommets du décor écrivent enfin leur position (0.49).

Limites : certains éléments restent noirs, températures élevées.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
