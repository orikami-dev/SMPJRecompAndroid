# 0.52

Chargements rapides et nouvelle manette tactile.

- Gestion de la mémoire du jeu en O(log n) : chargements de 35 s à 46 ms dans le test.
- Nouvelle manette tactile au thème fête, mêmes tailles sur les deux écrans du pliable.
- Bouton x2 pour accélérer le jeu ; compteur d'images par seconde discret avec températures.

Limites : quelques éléments 3D noirs, un plantage connu.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
