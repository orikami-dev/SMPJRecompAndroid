# 0.15

Première version testée sur le téléphone avec écran titre et menu principal.

- Le jeu démarre, passe l'intro et atteint l'écran titre.
- Après un plantage, le rapport du lancement précédent est écrit dans `rapport.txt` et proposé au partage.
- Manettes physiques 1 à 4 reconnues.

Limites : 3D encore noire, pas de son, pas de manette tactile.

**Installation** : il faut ta propre copie du jeu et tes propres clés ; ni le jeu ni les clés ne sont fournis. L'APK est distribué à part, pas dans ce dépôt.

Basé sur le runtime natif de Super Mario Party Jamboree (GPLv3).
